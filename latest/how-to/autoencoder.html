Fill gaps and fit a track with the autoencoder#

This guide shows how to give every sample a value of \(\gamma\), including samples an orderer left out, and fit a smooth mean track through them. The autoencoder explains how the network is trained.

In one call#

fit_track() runs the default pipeline, builds an autoencoder, and trains it:

import jax
import jax.numpy as jnp

import phasecurvefit as pcf

pos = {"x": jnp.linspace(0, 5, 50), "y": jnp.sin(jnp.linspace(0, jnp.pi, 50))}
vel = {"x": jnp.ones(50), "y": jnp.cos(jnp.linspace(0, jnp.pi, 50))}

config = pcf.nn.TrainingConfig(show_pbar=False)
ordering, result, losses = pcf.fit_track(
    pos, vel, key=jax.random.key(0), training_config=config
)

ordering is the default pipeline’s result, result the trained AutoencoderResult, and losses the training loss per epoch.

By default fit_track leaves out of the ordering the samples its outlier mixture calls background, so the track does not bend out to interlopers at its ends (The autoencoder explains how). Left-out samples have -1 in ordering.indices. Pass outlier_mixture=None to keep every sample in the ordering:

ordering, result, losses = pcf.fit_track(
    pos,
    vel,
    key=jax.random.key(0),
    outlier_mixture=None,
    training_config=config,
)

Step by step#

Build the pieces yourself to use a different orderer, a pre-built model, or another decoder. train_autoencoder accepts any orderer’s result:

ordering = pcf.order(pos, vel)

key = jax.random.key(0)
normalizer = pcf.nn.StandardScalerNormalizer(pos, vel)
autoencoder = pcf.nn.PathAutoencoder.make(
    normalizer, gamma_range=ordering.gamma_range, key=key
)

result, _, losses = pcf.nn.train_autoencoder(
    autoencoder, ordering, config=config, key=key
)

Read the result#

result.gamma holds \(\gamma\) for every sample, and result.membership_prob the encoder’s membership probability. Calling the result with values of \(\gamma\) evaluates the track. Draw it over result.track_range, which stops where the samples thin out at each end:

import matplotlib.pyplot as plt

track = result(jnp.linspace(*result.track_range, 200))

fig, ax = plt.subplots(figsize=(6, 3))
im = ax.scatter(pos["x"], pos["y"], c=result.gamma, s=15)
ax.plot(track["x"], track["y"], c="k", lw=1, label="track")
fig.colorbar(im, ax=ax, label=r"$\gamma$")
ax.legend();

Training runs in three phases with different objectives, so compare losses only within a phase. The stream autoencoder tutorial shows how to read the loss curve and check the final model.

Change the training settings#

TrainingConfig sets the epochs and loss weights of each phase:

config = pcf.nn.TrainingConfig(
    n_epochs_encoder=800,  # encoder only
    n_epochs_decoder=100,  # decoder only
    n_epochs_both=200,  # both networks together
    batch_size=100,
    lambda_prob=1.0,  # membership loss weight
    lambda_q=1.0,  # spatial reconstruction loss weight
    lambda_p=(1.0, 150.0),  # velocity alignment weight, ramped over phase 3
    show_pbar=False,
)
result, _, losses = pcf.nn.train_autoencoder(
    autoencoder, ordering, config=config, key=key
)

  • lambda_p is the (start, stop) of the velocity-alignment ramp in the joint phase. A higher stop value, 100 to 150, enforces stronger alignment.

  • n_epochs_encoder defaults to 800. A few hundred gives a quicker, rougher fit.

  • batch_size: larger batches are more stable but use more memory.

Options and defaults lists every setting with its default.

Train on an image or a wide curve#

When the samples spread wide across the track, as the pixels of an image do, freeze the encoder in the joint phase and use large batches (Density fields explains why):

config = pcf.nn.TrainingConfig(
    freeze_encoder_final_training=True,
    batch_size=1000,
    show_pbar=False,
)

If the image is a mask, such as a segmentation map, also set track_ends="mask" so the track ends where the curve inside the mask ends, rather than partway into the mask’s rounded ends:

config = pcf.nn.TrainingConfig(
    freeze_encoder_final_training=True,
    batch_size=1000,
    track_ends="mask",
    show_pbar=False,
)

Use a faster, training-free track#

If speed matters more than accuracy, for example inside a likelihood evaluated at every step of an MCMC, a RunningMeanDecoder can replace the trained decoder. The stream running-mean tutorial shows how, and when it is accurate enough.

To reject interlopers while training, see Reject outliers with the mixture model.
