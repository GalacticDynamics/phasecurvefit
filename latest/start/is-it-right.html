Is phasecurvefit right for my data?#

phasecurvefit fits when three things hold. You have many samples. Each sample has a position and a velocity, given as dictionaries of arrays with the same keys. And the samples lie along one curve whose order you don’t know. The tables below match what you have and what you want to the call to use and the page to read.

What phasecurvefit does not do#

  • Each call orders one curve. The default pipeline joins disconnected pieces into one ordering, so separate distinct streams in a catalogue before you order them.

  • It does not model the dynamics. The track is a smooth curve through the data in phase space, and phasecurvefit fits no orbit, potential or progenitor.

  • The local-flow walk does not choose its own start point. Chaining an MSTOrderer in front of it supplies an end of the curve (Chain orderers).
