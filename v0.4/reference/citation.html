Citation#

If you use phasecurvefit in published work, please cite the package itself, together with the paper behind each component you used. What to cite depends on which parts of the library ran, so the table below is keyed on the names you actually call.

Citing the package#

Cite the software via its Zenodo DOI, 10.5281/zenodo.18714340. Machine-readable metadata, including the component papers below, is in CITATION.cff; GitHub’s “Cite this repository” button reads it and produces BibTeX or APA.

What else to cite#

The default pipeline, pcf.order(pos, vel), is an MST backbone refined by a SOM, so the ordering needs the SOM paper and no other:

If you use …

also cite

the default pipeline: pcf.order(pos, vel) with no orderer, default_pipeline()

Starkman et al. (2023)

SOMOrderer, the phasecurvefit.som module

Starkman et al. (2023)

momentum-weighted ordering: LocalFlowOrderer, the default AlignedMomentumDistanceMetric

Nibauer et al. (2022)

the autoencoder: PathAutoencoder, train_autoencoder(), fit_track()

Nibauer et al. (2022)

mixture-model membership for outlier rejection: MixtureMembershipConfig (see Outlier rejection with a mixture model)

Hogg, Bovy & Lang (2010)

MSTOrderer alone

nothing beyond the package

These add up. fit_track() runs the default pipeline and then trains the autoencoder, so it cites both Starkman et al. (2023) and Nibauer et al. (2022). A local-flow walk followed by the autoencoder cites Nibauer et al. (2022) alone.

Nibauer et al. (2022) is the source of the local-flow walk and the autoencoder, not of the default ordering: cite it when you use one of those, not merely because you called pcf.order.
