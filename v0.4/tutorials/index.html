Tutorials#

Each tutorial is a complete analysis that runs from simulated data to a result. The groups follow the kind of data you have; start with the group that matches yours. New to phasecurvefit? Begin with the Quick start, then the stream autoencoder tutorial.

The notebooks need the tutorials extra, which adds matplotlib and galax (Install). Continuous integration runs every notebook on each change, so each one is checked to run with the current code.

A stream with velocities#

  • Learning a Stream with an Autoencoder: order a simulated stellar stream from its progenitor, fit its mean track, and read the training loss. Start here.

  • Learning a Stream with a Running Mean: a faster, training-free mean track for the same stream, and when it is accurate enough.

No known start point#

  • Ordering a Mock Stream with the MST Backbone: order a stream with no progenitor or start index, and reject injected interlopers.

  • Ordering a Self-Intersecting Epitrochoid with the MST Backbone: why the MST needs velocities on a self-crossing curve, and a Fourier-feature decoder.

A curve that crosses itself#

  • Learning an Epitrochoid with an Autoencoder: order a curve that crosses itself, using velocities to stay on the right strand.

  • Learning an Epitrochoid with a Running Mean: why a running mean cuts inside tight bends, and how the window size controls it.

Contaminated data#

  • Outlier rejection with mixture-model membership: reject interlopers with a stream-plus-background mixture model, and see why the orderers alone can’t.

An image or density map#

  • Fitting a Track Through a Density Image: fit a track through an image of a wide, diffuse curve, with each pixel a sample weighted by its value.
